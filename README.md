# 基于VUE的JSON格式化工具

## node版本
```
支持8.16.2、10.17.0、12.16.1、14.16.0、15.12.0五个版本
```


## 使用方法
```
npm install
```

### 开发模式
```
npm run serve
```

### 项目打包
```
npm run build
```
